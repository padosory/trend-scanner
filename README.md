# trend_scanner

STEP2 + RS 돌파 모멘텀 스캐너 (KOSPI/KOSDAQ).

## 용도 (현재 확정)

**시장 학습·모니터링 도구.** 실거래·자본 배분에는 쓰지 않는다.

- 매일 STEP2 + RS 돌파 종목을 스캔
- HTML 리포트로 패턴을 눈에 익힘
- Telegram 알림으로 시장 흐름을 추적
- GitHub Pages 배포 (Phase 1 완료)

매매도 자본도 개입하지 않으므로, 체결 현실성·통계적 엄밀성이 결과를 좌우하지 않는다. 가치의 원천은 완성된 Phase 1(스캔 → 리포트 → 알림)이다.

## 알파 검증 종료 결정 (2026-07)

실탄 배포를 목표로 한 백테스트 검증(P0-2 이후)은 **종료**했다.

배경: strategy_lab에서 게이트를 전부 통과한 *진짜* 엣지(저PBR 단독 CAGR 10.3%)조차, 기존 ETF 포트폴리오에 블렌드하니 S&P500 단독을 이기지 못했다 — KOSPI200과 상관 0.770(하락장에서 동반 하락), 전략 배분을 늘릴수록 샤프 단조 감소. 종착 판정 기준은 "게이트 통과"가 아니라 **"S&P500 Buy&Hold 대비 위험조정 우위"**였다.

이 전략의 엣지 정체 — **짧은 보유 × 저유동성 폭등주** — 는 strategy_lab이 이미 "ETF를 못 이긴다"고 판정한 영역과 겹친다. 따라서 실탄 검증을 이어갈 근거가 없다고 판단하고, 알파 검증을 하나의 확정된 "아니오"로 마감한다.

- 커밋 `a709c7f`: 거래정지 방어 로직 + 용도 확정
- P0-1 판정(4개 시나리오 A/B/C/D 비교)은 "체결 착시 크기"를 학습용으로 확인하는 선에서만 유지. (`p0_1_verdict.py`)
- P0-2, P0-3, P1 전부 중단.

## 승격 조건 (모니터링 도구 → 실탄 알파 검증 재개)

이 도구를 실탄 후보로 승격하려면 아래를 **순서대로** 통과해야 한다. 싼 검증이 비싼 검증을 막는 사다리 구조이며, 어느 하나라도 실패하면 승격하지 않는다.

### 전제 게이트 (필요조건)

싼 것부터. 앞 단계를 통과하지 못하면 다음으로 가지 않는다.

1. **체결 현실성** — P0-1/2/3 통과 후에도 평균 > 0, 전 연도 양수.
   - P0-1: 체결 시점 T종가 → T+1 시가 (B안)
   - P0-2: 진입 시점 상한가 잠김 제외 (보유 중 상한가는 유지)
   - P0-3: 2026 세금 + 거래대금 분위 차등 슬리피지
2. **취약성** — 상위 20건이 총수익을 지배하지 않음(집중도 점검) + MDD가 링펜스 손실한도(전체 자본의 10%) 이내.
3. **실체결** — 1~2달 가상매매 로그에서 실제 체결·슬리피지가 백테스트와 일치.

### 최종 관문 (이것이 없으면 승격 불가)

4. **S&P500 Buy&Hold 대비 위험조정 우위** — 기존 ETF 포트폴리오에 이 전략을 배분했을 때, 블렌드 샤프가 S&P500 단독을 넘고, 하락장에서 상관이 튀지 않을 것.

> 1~3은 "이 엣지가 가짜(체결 아티팩트)가 아님"을 증명한다.
> 4만이 "실탄을 옮길 값어치가 있음"을 증명한다.
> strategy_lab의 저PBR 단독은 1~3에 해당하는 검증을 통과하고도 4에서 죽었다.
> **미래의 충동 방지선: 4를 넘는다는 증거가 나오기 전에는 S&P500에서 자본을 옮기지 않는다.**
